使用教程

按下面顺序完成：安装环境 → 启动本地演示 → 连接直播间 → 采集直播画面。请先解压完整源码，不要直接双击 index.html 运行游戏。

01 / 第一次安装

  1. 准备 Windows 10 / 11、可联网环境与支持 WebGL 的显卡驱动。建议先用标准画质。
  2. 安装 Python 3.12（勾选 Add python.exe to PATH 和 Python Launcher）。
  3. 安装 Node.js 22 或 24 LTS。不需要执行 npm install。
  4. 安装或修复 Microsoft Edge WebView2 Evergreen Runtime。
  5. GitHub 仓库点击 Code → Download ZIP，完整解压到可写目录，如 D:\Games\avatar-arena-community。
  6. 双击 install.bat。它检查环境、创建 .venv 并从 PyPI 安装固定版本依赖。失败时保留报错，修正环境后可重试。首次安装需要联网。
  7. 安装完成后双击 start.bat。控制台会打开；启动失败时命令窗口会保留错误，便于排查。

本机验证环境为 Python 3.12、Node.js 24 与 WebView2。其他电脑仍应先按本教程做演示验收。

02 / 不开播也能体验

  1. 打开程序即有虚构观众对战，不会发送真实评论或礼物。
  2. 右侧「演示」选择观众，输入「红」或「蓝」，点击模拟评论。
  3. 选择小心心或墨镜，点击模拟赠送礼物；例如 2 个墨镜排队生成 20 个本人分身。
  4. 按住鼠标拖动旋转，滚轮缩放；「还原视角」恢复默认。
  5. 可导入本地 PNG/JPG 头像，图片只用于本机演示。暂停会冻结战斗和回合计时。

03 / 配置互动规则

在「互动规则」打开或关闭评论、点赞、进场、关注与礼物出兵。默认只开评论和礼物。普通互动可设置人数和小人体型，礼物采用固定人数：小心心 3、墨镜 10、其余 1。全部徒手；自定义礼物人数与冷兵器属于完整版。

规则自动保存在本机浏览器配置中，对新收到的事件生效。礼物优先插队、语音答谢、欢迎语音、自动演示与冷场补位可以单独设置。冷场补位默认关闭，开启后的模拟单位不计入真实阵营击倒数。

04 / 连接真实抖音直播间

  1. 直播间必须正在直播。在「直播连接」输入数字房间号，或 https://live.douyin.com/房间号，不能填个人抖音号或短链。
  2. 点击「打开直播间窗口」，在新窗口自行完成登录及验证。不要把 Cookie 或登录配置发给别人。
  3. 返回控制台点击「开始抓取」。显示“数据桥已连接”后，再核对是否收到真实评论。
  4. 让测试观众评论「红」或「蓝」，核对昵称、头像、阵营和人数。未核对成功前不要认定直播接入已经完成。
  5. 停止时点「停止抓取」，程序切回演示模式；临时断线会暂停并尝试重连。

程序只读取本机直播窗口中的互动并生成本地画面，不负责开播或推流。真实礼物读取、连击数量、头像身份与 OBS 推流仍需在你的直播环境验证；不承诺所有事件都准确或完整。部分点赞头像使用上游名单轮换，拿不到头像时显示昵称首字。

05 / 在 OBS 中展示

  1. 选择横屏 1280×720，或竖屏 1080×1920；点「弹出直播画面」。
  2. OBS 新增「窗口采集」，选择「头像角斗场免费版 · 直播画面」。
  3. 保持主控制台和画面窗口开启，不要最小化；在 OBS 中按画面比例缩放。
  4. 先用 OBS 本地录制验证画面持续更新，再按平台规则开播。

横竖屏小窗共享同一战局。OBS 采集失败时先检查选中的窗口、WebView2、显卡驱动与 OBS 捕获方式。

06 / 胜负与换队

每局 90 秒，按红蓝阵营击倒数决胜；同分平局。7 秒结算后自动开新局，未上场援军继续保留。已参战用户本局锁队，期间发送另一阵营指令将于下局生效。免费版不保存个人积分、胜场和段位。

07 / 常见问题

缺少 Python / Node.js，或安装失败？

安装上面的指定版本后重新打开 install.bat。如果网络无法访问 PyPI，请先排查网络。自定义位置的 Python 3.12 可用 PowerShell 执行 powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -PythonExe "C:\你的Python312目录\python.exe"。依赖错误可用 .venv\Scripts\python.exe -m pip check 查看。

黑屏、白屏、3D 初始化失败？

确认 WebView2 和显卡驱动正常，先使用标准画质；保留 start.bat 的错误。不要只复制单个 HTML 文件，assets 目录必须完整。

评论来了，礼物没进场？

先检查礼物触发是否开启、队列是否满、平台返回的礼物名称和数据桥日志。平台改版、登录失效、事件解析遗漏均可能影响读取，不应仅靠重新购买版本判断能解决。

设置和登录数据在哪里？

设置与登录资料在本项目的隐藏 profile 目录，另有 .bridge-room、avatar-cache.json 和日志。它们只留本机，不应上传 GitHub 或发送给他人；源码发布脚本会排除这些文件。
